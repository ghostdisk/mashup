# Assets

The procedural starter's geometry is generated in code. Put any future original or properly
licensed redistributable assets here with their provenance and notices.

Player-owned converted game content goes under `assets/imported/<game>/`, which
Git ignores and which must be excluded from releases. Source files and conversion
staging belong in the ignored `user_data/` directory. These local directories are
created when needed. See [`docs/goldsrc-import.md`](../docs/goldsrc-import.md) for
the explicit local Half-Life / Counter-Strike import workflow.
